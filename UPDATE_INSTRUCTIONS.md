# Как работает автообновление

## При запуске программы
Программа автоматически проверяет обновления при каждом запуске (через 1 секунду после старта).

## Если есть обновление
1. Появится диалог: "Вышла новая версия: X.X.X, текущая: Y.Y.Y. Хотите обновить?"
2. Если нажать **Да** — скачается новая версия и программа перезапустится
3. Если нажать **Нет** — можно продолжить работу со старой версией

## Как выпустить обновление

### 1. Обновите версию в config.py
```python
APP_VERSION = "1.0.1"  # Увеличьте номер версии
```

### 2. Скомпилируйте новую версию
```bash
pyinstaller --onefile --windowed --icon=icon.ico --name=ZapretUpdater main.py
```

### 3. Создайте релиз на GitHub
1. Зайдите в ваш репозиторий на GitHub
2. Перейдите в **Releases** → **Draft a new release**
3. В поле **Tag version** напишите: `1.0.1` (должно совпадать с `APP_VERSION`)
4. В поле **Release title** напишите: `Release 1.0.1`
5. Прикрепите файл: `dist/ZapretUpdater.exe` (важно! имя должно быть `ZapretUpdater.exe`)
6. Нажмите **Publish release**

### 4. Готово!
Все пользователи с旧 версией получат уведомление об обновлении при следующем запуске.

## Важно!
- Имя `.exe` файла в релизе должно быть **точно** `ZapretUpdater.exe`
- Версия в `config.py` должна совпадать с тегом релиза на GitHub
- GitHub API может быть заблокирован в некоторых странах (но обычно работает)

## Файлы
- `config.py` — здесь хранится `APP_VERSION`
- `app_updater.py` — логика проверки и установки обновлений
- `github_api.py` — функция `get_latest_app_release()` для получения `.exe` из релиза
- `app_release_cache.json` — кэш данных о последнем релизе (создается автоматически)
