# Zapret Auto Updater

> ⚠️ **ВНИМАНИЕ!**  
> Программа создана в **учебных целях** для практики работы с **Git** и изучения **Python**.  
> Не предназначена для коммерческого использования.

---

## 🚀 Что делает программа

Автоматически проверяет версию [Zapret](https://github.com/Flowseal/zapret-discord-youtube) на вашем ПК и сравнивает с последней версией на GitHub (через RSS-ленту).  
Если версия устарела — **удаляет старую и устанавливает новую**.

---

## 📦 Возможности

- ✅ Определение установленной версии Zapret (читает `service.bat`)
- ✅ Проверка последней версии через RSS GitHub (работает без VPN)
- ✅ Скачивание и распаковка архива
- ✅ Автоматическое удаление старой версии
- ✅ Консольная версия (`main.py`)
- ✅ Графический интерфейс (`gui.py`) на tkinter
- ✅ Сохранение настроек между запусками
- ✅ Кэширование данных при отсутствии интернета
